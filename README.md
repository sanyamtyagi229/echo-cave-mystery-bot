# 🕵️‍♂️ Echo Cave Mystery Bot

An interactive multi-language mystery chatbot built on **Botpress Cloud**. It features **50 unique clues** with multilingual support (English, Hindi, and Punjabi) and a progressive riddle-solving mechanism.

## 🚀 Play Live Bot
You can directly play and test the bot here:
👉 [Play Echo Cave Mystery Bot](https://cdn.botpress.cloud/webchat/v3.7/shareable.html?configUrl=https://files.bpcontent.cloud/2026/10/15/05/20261015053305-K7TN4OMF.json)

## ✨ Features
- **50 Challenging Clues:** Test your wits across progressive mystery archives.
- **Multilingual Support:** Play in English, Hindi, or Punjabi.
- **Interactive Commands:** 
  - Type your answer to solve clues.
  - Type `'explain'` for helpful hints.
  - Type `'exit'` to save your progress and quit.

## 🛠️ Built With
- **Botpress Studio** (Cloud Agent & Workflow Management)
- **Botpress Tables** (Database storage for all 50 clues and multilingual text)
